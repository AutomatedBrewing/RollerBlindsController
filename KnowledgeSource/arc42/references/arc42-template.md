arc42 is a pragmatic, open-source template for the documentation of software and system architectures. It was created and is maintained by Dr. Peter Hruschka and Dr. Gernot Starke, with contributions from a wide community of practitioners. The template is freely available under a Creative Commons licence and has been widely adopted across the software architecture community as a lightweight alternative to heavyweight documentation standards.

The version covered by this knowledge bundle is Template Version 9.0-EN (based upon AsciiDoc version), released in July 2025. This version structures architecture documentation into twelve numbered sections, each addressing a distinct aspect of the architecture. The twelve sections are designed to be used selectively — teams are encouraged to omit or abbreviate sections that do not add value for their particular system and audience, rather than filling in every placeholder for its own sake.

The template is technology-agnostic and process-agnostic: it can be used with any development process (waterfall, agile, or hybrid) and does not prescribe any particular notation or tooling. It provides a consistent structure that enables reuse of documentation across projects and simplifies architectural reviews by giving reviewers a predictable layout to navigate.
