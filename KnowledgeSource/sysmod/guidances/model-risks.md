Guidance 7.7 in SYSMOD. This guidance describes how to model Risks in the SysML system model.

# Context

- **SYSMOD Method:** [4.9 Model Risks](../methods/model-risks.md)
- **SYSMOD Product:** [5.9 Risks](../products/risks.md)
- **SYSMOD Role:** [Requirements Engineer](../roles/requirements-engineer.md)

# Description

Each Risk is documented in a table to store the information in a uniform structured format. The Risk model elements are created as SYSMOD risk elements in the dedicated Risks package.

# How to Model

1. Select the package `<system>Risks`.
2. Create a table to depict the Risks.
3. For each identified Risk, create an appropriate SYSMOD risk element and fill out its properties.
