Method 4.3 in SYSMOD. An MBSE Methodology must be actively deployed to be accepted and adopted by the organization. Deployment is a change process that requires time and active management.

# Purpose

An MBSE Methodology must be actively deployed to be accepted and to be adopted by the organization.

# Description

The deployment of the MBSE Methodology should enable its successful application. The methodology should not be introduced in one step; instead, define intermediate goals—for example, according to the levels SYSMOD1 to SYSMOD3 in the SYSMOD Model Purpose Model. Think big and start small.

Deploying MBSE is a change process that needs time to be successfully adopted. Projects must use methods and tools effectively and valuably from the early beginning. It is essential to integrate new methods as a mandatory part of the engineering process; optional parts tend to be discarded when schedules get tight.

Keep an eye on the value/effort relation from three perspectives: the short-term project perspective, the long-term organization perspective, and the human perspective of the engineers doing the work.
