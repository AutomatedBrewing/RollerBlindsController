The SYSMOD Infrastructure Process is one of the four primary SYSMOD Processes. It covers the initial setup work required before any system analysis or architecture activity can begin. Its purpose is to prepare the organization with the right methodology, tools, and trained people.

# Purpose

The Infrastructure Process ensures that the MBSE Methodology is defined, the System Modeling Environment (SME) is configured and operational, and the engineering teams possess the necessary skills to apply MBSE effectively.

# Description

The SYSMOD Infrastructure Process produces three foundational products: the MBSE Methodology, the System Modeling Environment (SME), and the MBSE Training. These outputs are prerequisites for the Analysis and Architecture Processes.

The process is executed primarily at project or organization start, but it may be revisited when methodology updates or tool changes are required. SMAP (the SYSMOD MBSE Adoption Process) uses SYSMOD itself to derive a customized MBSE Methodology—in that case, the MBSE Methodology itself is the system of interest.
