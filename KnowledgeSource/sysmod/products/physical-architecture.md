# Purpose

The Physical Architecture represents the common concepts of all System Architecture kinds for physical entities.

# Description

The Physical Architecture is an abstract concept that encompasses the Logical Architecture, Product Architecture, Base Architecture, and Test Architecture. Note that software is also a physical element and part of the Physical Architecture—a physical element represents a real-world element.

The SEBoK defines a Physical Architecture as "an arrangement of physical elements (system elements and physical interfaces) which provides the design solution for a product, service, or enterprise, and is intended to satisfy logical architecture elements and system requirements."

In SYSMOD's terminology, the "design solution" part aligns with the Product Architecture, while the "intended to satisfy logical architecture" part aligns with the Logical Architecture.

# Relationships

The Physical Architecture is an abstract concept and therefore has no relationships with other SYSMOD elements and no representations.
