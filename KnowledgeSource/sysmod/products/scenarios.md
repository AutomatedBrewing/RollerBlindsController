# Purpose

A Scenario checks whether all parts and connections exist for a specific system function.

# Description

A Scenario describes how parts of the system collaborate to perform a single path through a Use Case Activity. When specifying a scenario, you must check if all necessary parts and connections are correctly defined in the model. The modeler does a virtual tour through the system and checks if everything is in place.
