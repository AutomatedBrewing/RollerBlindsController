Product 5.17 in SYSMOD. The System Architecture represents the common concepts of all architecture kinds of a system.

# Purpose

The System Architecture represents the common concepts of all architecture kinds of a system.

# Description

The System Architecture is an abstract SYSMOD Product—it does not exist in reality. Only one of its specialized architecture kinds exists:

- Base Architecture
- Functional Architecture
- Physical Architecture
- Logical Architecture
- Product Architecture
- Test Architecture

The System Architecture is the root of the SYSMOD architecture taxonomy.

# Relationships

The System Architecture is an abstract concept and therefore has no direct relationships with methods or roles.
