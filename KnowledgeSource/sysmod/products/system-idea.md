# Purpose

The System Idea is a brief description of the purpose of the system, including a list of the main features with a particular focus on the uniqueness of the system ("elevator pitch").

# Description

The System Idea is the short answer to "What are you building and why are you doing this?" and "What is the value for the customer of the system?". This basic knowledge gets easily lost in all the details of a complex development project.

Typically, the System Idea is stored somewhere else in the documentation of product management. In that case, the SYSMOD Product System Idea is a proxy for the source to establish a link to the engineering team.
