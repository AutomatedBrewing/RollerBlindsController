# Purpose

The SME must be customized to effectively facilitate the SYSMOD Methods and the daily work of the engineers and Stakeholders.

# Description

In most cases, modeling tools cannot be used out-of-the-box. The SME is a set of modeling tools, configuration files, plugins, and so forth necessary to customize the tools for the MBSE Methodology.

A SysML modeling tool is the core of the SME. Some typical customizations of the SME include:

- Enable access to model libraries
- Load SysML profiles
- Adapt the user interfaces of the modeling tools
- Set up connections to other tools
- Set up the configuration management for the model repositories
