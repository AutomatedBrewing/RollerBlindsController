# Purpose

The System Use Cases provide a view on the system functions from the perspective of the system actors and enable an optimized development of the requirements and the usability of the system.

# Description

A System Use Case is triggered by a system actor and returns a result that is of value for actors or Stakeholders of the system. The behavior is temporally cohesive—there is no temporal interruption supported by the system.

The properties of a System Use Case include: the associated system actors, the trigger, the result, a brief textual description (2–5 sentences), pre- and postconditions, and the Use Case Activity.

The Continuous Use Case is a special System Use Case representing continuous behavior of the system.
