Appendix A in SYSMOD. The following mapping shows the ISO 15288 processes and the corresponding SYSMOD Methods. The mapping makes no distinction between full or partial coverage.

# Purpose

Provides a reference mapping between ISO 15288 (Systems and Software Engineering — System Life Cycle Processes) and the SYSMOD Methods, enabling organizations to align SYSMOD with ISO 15288-based process landscapes.

# Description

SYSMOD Methods and Products can be used in the context of an ISO 15288-inspired process landscape. The mapping below shows which SYSMOD Methods correspond to each ISO 15288 process. Many ISO 15288 processes are not explicitly covered by SYSMOD.

# Relationships

All mapped methods are listed below with their ISO 15288 process categories.
