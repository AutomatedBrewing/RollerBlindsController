Role 6.3 in SYSMOD. The Project Manager is the manager of the systems development project.

# Description

The Project Manager manages the project and is partly directly involved in the SYSMOD Methods. The Project Manager must have excellent skills in project management; since project management is out of scope for SYSMOD, that skill is not covered by the SYSMOD skills map.
