Role 6.1 in SYSMOD. The SME Administrator sets up the SME of the systems engineering project.

# Description

The SME Administrator sets up the SME of the systems engineering project. That includes:

- Configuration of the modeling tools (customizing, installing profiles, add-ons, and libraries)
- The configuration management environment for the models and engineering artifacts (e.g., a repository server)
- Installation and configuration of adapters to other engineering tools like a requirements management tool, PLM, CAD, or a simulation tool

The SME Administrator has a close interface to the MBSE Methodologist. For example, implementing and deploying a model query requires knowledge about the methodology and language architecture as well as programming and tool skills. Conversely, special features of a tool can make methodical steps possible in the first place.
