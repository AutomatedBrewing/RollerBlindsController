Role 6.5 in SYSMOD. The System Architect is responsible for the System Architecture.

# Description

The System Architect derives the solution space from the problem space (requirements). The role closely communicates with the Requirements Engineer.

In SYSMOD, the Systems Engineer is a collective term for Requirements Engineer, System Architect, and System Tester.
