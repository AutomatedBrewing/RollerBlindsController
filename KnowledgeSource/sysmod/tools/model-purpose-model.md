Tool 11.3 in SYSMOD. The SYSMOD Model Purpose Model (previously named the SYSMOD Intensity Model) is a simple description of three levels of modeling objectives.

# Purpose

The Model Purpose Model guides MBSE adoption by defining increasing levels of modeling capability, from communication-focused to full MBSE.

# Description

The Model Purpose Model has three levels and two add-ons:

**SYSMOD1: Purpose Communication** — The objective of modeling is to improve communication between stakeholders and other interested parties. The model and its views enable clear communication and provide a holistic view of the system. Communication and understanding are more important than formalism and completeness.

**SYSMOD2: Purpose Traceability** — Elements in the model are linked in a predefined manner to enable traceability queries with complete and proper results. For example, from a Requirement to all elements in the architecture that satisfy the Requirement or vice versa.

**SYSMOD3: Purpose Specification** — The models are the primary source of the systems engineering data for the engineering processes. Documents are only views on the model. Only SYSMOD3 is real MBSE.

**SYSMOD_LIB: Libraries** — Common elements of the model are extracted and moved into model libraries for reuse in other projects.

**SYSMOD_SIM: Simulation** — The model is used to run a simulation or other automatic analysis to validate the model or to get further insights, for example, trade-off studies.

SYSMOD1 and SYSMOD2 are Model-Supported Systems Engineering (MSSE)—the models support the engineering processes, but the primary source of engineering data is mostly documents.
