Tool 11.9 in SYSMOD. The Product Vision Board is a canvas proposed by Roman Pichler that provides a good overview of the main pillars of a product vision.

# Purpose

The Product Vision Board can be used well in workshops to elaborate the product vision, covering System Idea, System Objectives, and stakeholder aspects.

# Description

The Product Vision Board template has sections that cover System Idea and System Objectives, but also other aspects like the Stakeholders. It provides a structured canvas for developing and communicating the product vision to all relevant parties.

The Product Vision Board was proposed by Roman Pichler [Pi16] and is a widely used tool in agile product development.
