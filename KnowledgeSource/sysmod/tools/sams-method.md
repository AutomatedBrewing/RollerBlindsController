Tool 11.10 in SYSMOD. The Storyboard Activity Modeling for Systems (SAMS) method supports the elaboration of use cases based on storyboards.

# Purpose

The SAMS method supports the elaboration of System Use Cases and the System Idea based on storyboards, with traceability between the storyboards and system models.

# Description

Walt Disney Productions developed storyboards in the 1930s to pre-visualize motion pictures. The SAMS method uses storyboards as a tool for the analysis of requirements.

Participants of a SAMS workshop include a storyboard designer with sufficient drawing talent and the relevant stakeholders of the system development project. The storyboard designer visualizes the storyboards in real-time while participants see the progress. The storyboard leads to new ideas or refinements of existing ones.

At the end of this iterative process, you have a set of storyboards visualizing usage scenarios of the system of interest (similar to concepts of operations, ConOps). The storyboards are the source to derive System Use Cases. The storyboard snippets can be integrated into the model, and traceability can be established between the storyboard snippets and the System Use Cases.

The storyboards can also be used to clarify or derive the System Idea.
